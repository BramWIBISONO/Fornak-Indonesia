# Sistem desain

Palet utama berasal dari token yang sudah ada di premium.css. Merah lembaga #B70E24, burgundy #780D23, gading #F7F4EE dan tinta #17191D menjalankan peran berbeda. Teks sekunder diperkuat setelah pemeriksaan kontras. Manrope untuk judul institusional, Source Serif 4 untuk judul editorial dan kutipan, Inter untuk kontrol serta teks pendukung. Font disajikan dari proyek.

Komposisi baru memakai lebar dalam maksimal 1480 px, gutter fluida, dan titik perubahan utama 760 px. Hero melebar penuh. Kolom bacaan tetap dibatasi sesuai fungsi. Bentuk membulat dipakai pada kendali, sampul media dan tombol. Teks panjang memiliki jarak baris lebih longgar daripada judul.

Gaya per komponen berada di src/features/experience/folio.css, dengan token dasar tetap di src/premium.css. Transisi singkat memakai transformasi dan opasitas. Pengaturan gerakan terbatas menghentikan animasi masuk dan perspektif buku.
