# Desain interaksi

| Komponen | Tindakan | Umpan balik |
| --- | --- | --- |
| Foto pembuka | Sebelumnya dan berikutnya | Gambar, keterangan, dan nomor foto berubah. |
| Visi dan misi | Klik, sentuh, Enter, atau Spasi pada judul | Panel terbuka atau tertutup, ikon dan motif berubah. |
| Program | Pilih tab, gunakan panah atau Home/End, atau gunakan tombol langkah | Panel menampilkan uraian resmi dan simbol pilihan. |
| Rak publikasi | Pilih salah satu dari tiga judul | Sampul, kredit, halaman, tautan baca dan unduh diperbarui bersama. |
| Jurnal | Cari, saring topik dan buka artikel | Hasil dan jumlah tulisan berubah. Kembali memulihkan kueri. |
| Galeri | Saring, buka, perbesar, pindah, unduh, Escape | Dialog berfokus pada dokumen aktif. |
| Kontak | Buka chatbot atau kanal sekretariat | Asisten menjawab pertanyaan singkat, WhatsApp dan Instagram mengarah ke tujuan resmi. |

Gerakan tidak memerlukan input presisi. Kontrol navigasi memiliki nama aksesibel. Pencarian, galeri dan menu mendukung Escape. [Bukti pengujian alur](bukti/interaksi/journeys.json)
