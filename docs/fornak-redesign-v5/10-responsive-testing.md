# Pengujian responsif

Delapan rute utama diperiksa di Chrome dengan sembilan viewport, meliputi 360×800, 390×844, 430×932, 768×1024, 1024×768, 1280×800, 1440×900, 1920×1080 dan 2560×1440. Apertur CSS menggunakan zoom standar. Setiap halaman menunggu gambar dan font sebelum pengukuran lebar serta pemeriksaan gambar.

Pada ponsel, judul dan tombol mendahului foto, menu masuk ke navigasi seluler, program menjadi dua kolom pilihan, dan buku tampil di atas deskripsinya. Peluncur asisten menjadi tombol lingkaran agar tidak menutupi tautan cepat dengan label panjang. Pemenggalan *Iman yang bekerja* dikoreksi setelah tangkapan ponsel pertama.

Hasil 72 kombinasi tersedia per rute dan lebar. Tangkapan lengkap untuk 390 dan 1440 px ada di folder final. Ini merupakan pengujian viewport Chrome pada Windows. Perilaku perangkat fisik dan Safari iOS masih memerlukan verifikasi tersendiri. [Data pengujian](bukti/final/audit.json)
